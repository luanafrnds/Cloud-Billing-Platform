# 💳 Billing Analyzer

Aplicação desenvolvida em Python com Streamlit para auditoria de subscrições e créditos IBM Cloud.
(Projeto desenvolvido para uso interno do meu time).

## 🚀 Acesse a aplicação

https://cloudplatform.streamlit.app

## Funcionalidades

- Upload de arquivos CSV
- Análise de Billing Summary
- Análise Enterprise Consolidado
- Filtros por conta e mês
- KPIs de consumo, saldo e créditos contratados

## Tecnologias utilizadas

- Python
- Streamlit
- Pandas
- Plotly

Caso queria fazer o teste, baixe os arquivos com dados falso, "Faturamento Abril", "Faturamento Maio" e "Faturamento Subscrição", arraste e solte os arquivos na opção "Padrão - Instance / Billing"
