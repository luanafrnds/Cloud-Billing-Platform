# 💳 Billing Analyzer

Aplicação desenvolvida em Python com Streamlit para auditoria de subscrições e créditos IBM Cloud.

## 🚀 Acesse a aplicação

https://cloudplatform.streamlit.app

## Funcionalidades

- Upload de arquivos CSV
- Análise de Billing Summary
- Análise Enterprise Consolidado
- Filtros por conta e mês
- KPIs de consumo, saldo e créditos contratados

## Tecnologias utilizadas

- Python
- Streamlit
- Pandas
- Plotly
